# ASCII Text Images

A browser-based experiment that converts visual content into ASCII-style text art. The project explores how images can be represented using characters and rendered directly in the browser.

## Highlights

- Image-to-text / ASCII-art rendering
- Pure browser-side HTML and JavaScript
- Lightweight, dependency-free demo
- Visual exploration of pixel-to-character mapping

## Run locally

Open `textart.html` in a modern browser.
